# Xray 中文节点管理工具

面向 Linux VPS 的 SS / SS2022 节点管理工具。新手只需选择“一键创建”，完成后复制链接到客户端导入。

## 安装和打开

在 VPS 中执行：

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/fengqi0216/xray-deploy/main/install-xray-ss.sh)"
```

安装完成后自动打开菜单。以后输入 `xnode` 即可再次打开；普通用户使用 `sudo xnode`，安装时需具备 `sudo` 权限。

已下载本项目的用户，也可以在项目目录执行 `sudo sh install.sh`。

## 新手最快用法

1. 主菜单输入 **1**，自动创建一个节点。
2. 复制显示的完整 **`ss://` 链接**，在客户端选择“从剪贴板导入”。

首次创建会自动安装默认 Xray **v26.6.1**；已有内核时使用当前版本。节点名称、空闲端口、密码和公网 IP 自动准备，默认使用兼容常见客户端的 **SS / aes-256-gcm**，同时开启 **TCP + UDP**。以后再次选择 **1** 可以继续创建独立节点。

需要重新复制链接时，主菜单选择 **2**，直接显示所有节点的分享链接，无需记住节点名称。

如果无法自动获取公网 IP，脚本会提示手动输入服务器的公网 IPv4 或 IPv6。创建完成后，请按提示在 VPS 服务商安全组和服务器防火墙中放行节点端口的 TCP 和 UDP。

## 菜单怎么用

主菜单显示当前内核、服务状态和节点数量，常用操作放在前面：

```text
常用操作
  1）一键创建节点（推荐新手）
  2）查看 / 复制分享链接
  3）查看已有节点

管理与维护
  4）管理节点（连接信息 / 出站 JSON / 端口 / 删除）
  5）服务管理（状态 / 重启 / 日志）
  6）高级设置（自定义创建 / 内核版本 / 检测 / 卸载）

  0）退出管理系统
```

| 入口 | 功能顺序 |
| --- | --- |
| **4 · 管理节点** | 1 连接信息 / 链接；2 出站 JSON；3 修改端口；4 删除节点 |
| **5 · 服务管理** | 1 运行状态；2 重启 / 启动服务；3 运行日志 |
| **6 · 高级设置** | 1 自定义创建；2 安装 / 切换内核；3 系统兼容性检测；4 完全卸载 |

选择节点时可以输入**列表序号**，也可以输入原来的中文名称或 `ss-节点名`。只有一个节点时，管理入口会自动选中。各子菜单输入 **0** 返回，主菜单输入 **0** 退出。

菜单在支持颜色的终端中显示彩色分组，重定向输出时使用纯文本。可设置 `NO_COLOR=1` 关闭颜色。操作结果会留在终端中，方便复制链接。

## 自定义创建

主菜单选择 **6 → 1**，可以自行填写节点名称、加密方式、端口和连接地址：

- **名称**：支持中文、英文和常见符号；回车自动命名，最多 48 个字符。
- **加密**：回车使用 `aes-256-gcm`；也可以选择其他 SS 算法或 SS2022，客户端需支持对应算法。
- **端口**：回车自动选择空闲端口，也可以手动指定。
- **地址**：回车自动获取公网 IP；输入 `y` 后填写已解析到 VPS 的域名或 DDNS 域名。

填写域名只会改变该节点分享链接中的服务器地址，请先完成 DNS 解析。这里不会自动配置 DNS、HTTPS 或 TLS。不同节点的连接地址分别保存。

创建成功后会显示该节点的名称、地址、端口、密码和完整分享链接。

## 导出到 3x-ui

主菜单选择 **4**，选中节点后选择 **2**，复制显示的 Xray 出站 JSON。

将这个 JSON 对象加入 3x-ui 的 Xray 配置 **`outbounds` 数组**，再按需设置路由。它是单个出站对象，请勿替换整份配置。JSON 中的 `tag` 与显示的节点名称一致，例如 `ss-北京联通9929`。3x-ui 内核需支持该节点的加密算法。

旧版多用户节点的原有链接可通过主菜单 **2** 或 `xnode links` 查看。

## 常用命令

```bash
xnode                  # 打开中文管理菜单
xnode add              # 一键创建节点并显示链接
xnode custom           # 自定义创建节点
xnode links            # 查看全部节点分享链接
xnode list             # 查看带序号的节点列表
xnode show             # 选择节点，查看连接信息或出站 JSON
xnode status           # 查看服务状态
xnode logs             # 查看运行日志
xnode install-default  # 安装 / 切换到默认 Xray v26.6.1
xnode check            # 检测系统兼容性，无需 root
```

除 `check` 和帮助外，上述管理命令需使用 root 或 `sudo`。

## 更新和卸载

**更新工具：** 重新执行安装命令即可。更新管理脚本时会保留已有节点、连接地址和当前内核版本。

**更新 / 切换内核：** 主菜单选择 **6 → 2**，可以选择正式版、预发布版或手动输入版本号；直接回车使用默认版本。内核安装会验证 SHA256，并在切换前检查现有节点配置。

**删除单个节点：** 主菜单选择 **4**，选中节点后选择 **4**，输入 `确认删除`。

**完全卸载：** 主菜单选择 **6 → 4**，输入 `确认卸载`。会删除本工具管理的节点、密码、配置备份、服务和内核，请提前备份。完成后自动退出菜单。

## 系统支持

支持常见 Linux 发行版和多种 CPU 架构，具体以内核官方发布包为准。支持 systemd、OpenRC、SysVinit、runit、procd；无法识别服务管理器时使用手动模式，手动模式不支持开机自启。

安装前可以运行 `bash xray-ss.sh check` 检测系统兼容性，无需 root。正式运行时会尝试自动补齐依赖。
