# Xray 节点管理工具使用说明

## 一、一键安装

在 Linux VPS 终端执行：

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/fengqi0216/xray-deploy/main/install-xray-ss.sh)"
```

建议使用 `root` 用户执行。普通用户需要具备 `sudo` 权限。

安装完成后，输入以下命令打开中文管理菜单：

```bash
xnode
```

普通用户可使用 `sudo xnode`。

## 二、创建节点

1. 运行 `xnode`，选择 **1）安装或切换 Xray 内核版本**，按提示完成内核安装。
2. 选择 **2）添加 SS / SS2022 节点**。
3. 输入节点名称（支持中文），选择加密方式。
4. 输入节点端口；直接回车可随机生成端口。
5. 按提示选择连接地址：

   ```text
   此节点是否使用域名（含 DDNS）作为连接地址？[y/N]：
   ```

   - **直接回车或输入 `n`**：使用服务器公网 IP；无法自动获取时可手动填写。
   - **输入 `y`**：填写自己的域名或 DDNS 地址，例如 `ss.example.com`。

创建成功后，脚本会自动显示节点地址、端口、密码及完整 `ss://` 连接链接，复制到支持对应加密方式的客户端即可使用。

节点默认同时启用 **TCP 和 UDP**，无需额外选择。

> 使用域名时，请先确保该域名已解析到 VPS 的公网 IP。填写域名不会自动配置 DNS 或 TLS。还需要在服务器防火墙和云服务商安全组中放行节点端口的 TCP、UDP 流量。

## 三、查看节点链接或出站 JSON

运行：

```bash
xnode
```

选择 **4）查看节点连接信息 / 出站 JSON**，输入要查看的节点名称，然后选择：

```text
1）查看 SS / SS2022 连接链接
2）查看 Xray 出站 JSON
0）返回上级菜单
```

- **选项 1：** 查看完整 `ss://` 分享链接，可复制到客户端导入。
- **选项 2：** 查看该节点的 Xray 出站 JSON，适用于分享链接无法直接导入的情况，例如在 3x-ui 中手动配置出站。

导出的 JSON 会包含节点地址、端口、加密方式和密码，`tag` 与显示的节点名称相同。

使用时，把导出的**单个 JSON 出站对象**添加到 Xray 配置的 `outbounds` 数组中；如需让流量走该出口，还应配置对应的路由规则。不要用这个对象覆盖整个 Xray 配置。旧版 Xray 内核如果不支持所选加密方式，仍需使用兼容的内核。

## 四、常用命令

```bash
xnode                  # 打开中文管理菜单
xnode list             # 查看已有节点
xnode show             # 查看节点链接或出站 JSON
xnode links            # 查看全部节点分享链接
xnode status           # 查看 Xray 运行状态
xnode logs             # 查看 Xray 运行日志
xnode install-default  # 安装默认 Xray 内核
```

普通用户运行这些管理命令时，需在命令前加 `sudo`。

## 五、其他管理操作

在 `xnode` 中文菜单中，还可以使用：

| 菜单 | 功能 |
| --- | --- |
| `3` | 查看已有节点 |
| `5` | 修改节点端口 |
| `6` | 删除节点 |
| `7` | 查看服务运行状态 |
| `8` | 查看运行日志 |
| `9` | 重启 Xray 服务 |
| `10` | 完全卸载 |
| `11` | 检测 Linux 系统兼容性 |
| `0` | 退出管理系统 |

**卸载方法：** 运行 `xnode`，选择菜单 **10）完全卸载**，按提示确认。完全卸载会清除本工具管理的节点配置和密钥，请提前备份。

> `ss://` 连接链接和出站 JSON 均可能包含节点密码，请勿公开分享。
