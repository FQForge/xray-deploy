# Xray 中文节点管理工具

支持 **SS、SS2022、VLESS + Reality**，提供普通 VPS、NAT 端口映射、动态 IP 和 DDNS 创建向导。

## 安装和打开

在 Linux VPS 中执行：

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/fengqi0216/xray-deploy/main/install-xray-ss.sh)"
```

安装完成后自动打开菜单。以后输入 `xnode` 再次打开；普通用户使用 `sudo xnode`。已下载本项目时，也可以在项目目录执行 `sudo sh install.sh`。

## 新手怎么创建

主菜单选择 **1 · 快速创建节点**，按顺序选择：

```text
选择协议
  1）SS
  2）SS2022
  3）VLESS + Reality

选择网络环境
  1）独立公网 / 固定 IP（普通 VPS）
  2）NAT / 端口映射
  3）动态公网 IP + DDNS 域名
  4）NAT + 动态 IP + DDNS 域名
```

普通 VPS 选择协议后，网络环境直接回车即可。其他参数自动准备，完成后复制完整的 **`ss://` 或 `vless://` 链接**，在客户端选择“从剪贴板导入”。主菜单 **2** 可以随时重新复制所有节点的链接。

首次创建自动安装默认 Xray **v26.6.1**；已有内核时使用当前版本。名称、密码、UUID、Reality 密钥和空闲端口按需自动生成。

| 协议 | 快速创建使用的参数 | 客户端与端口要求 |
| --- | --- | --- |
| SS | `aes-256-gcm`，独立随机密码 | 常见 SS 客户端；放行 TCP + UDP |
| SS2022 | `2022-blake3-aes-256-gcm`，自动生成 32 字节密钥 | 客户端需支持 SS2022；放行 TCP + UDP |
| VLESS + Reality | TCP + Vision，自动生成 UUID、密钥和 short ID | 客户端需支持 Reality / Vision；放行 TCP |

## NAT：端口要怎么填

NAT 要使用服务商或路由器**已经分配的映射**。向导会问：

1. **公网访问端口**：客户端连接的外部端口。
2. **本机监听端口**：该外部端口转发到服务器上的哪个端口；如果内外相同，直接回车。
3. **公网 IP 或域名**：填写 NAT 面板或路由器对应的公网地址。

例如服务商分配了：

```text
公网 nat.example.com:31415 → VPS 内部端口 27001
```

就填写公网端口 **31415**、本机端口 **27001**、地址 **nat.example.com**。Xray 监听 **27001**，分享链接和出站 JSON 自动使用 **31415**。

**不知道端口时，输入 0 返回，先查看 NAT 面板或路由器的端口转发规则。** 脚本无法推断服务商尚未分配的公网端口，也不会替你配置外部路由器。只有出站网络、没有入站映射的 CGNAT 无法直接接入，可向服务商申请映射，或使用可入站的公网 IPv6 / 中转。

服务器防火墙放行本机端口；服务商安全组和路由器放行公网端口。SS / SS2022 的 TCP、UDP 需要各自的转发；只有 TCP 映射时 UDP 不可用。Reality 只需映射 TCP。

## 动态 IP：使用 DDNS

IP 经常变化时，选择网络环境 **3**；同时经过 NAT 时选择 **4**。节点保存域名，IP 改变后由 DDNS 更新解析，无需重新生成节点或改客户端地址。

创建时可选择：

- **已有 DDNS**：填写路由器、ddns-go 等已经持续更新的域名。
- **Cloudflare 自动更新**：填写自己的域名和 API Token，脚本自动寻找区域，创建或更新 A / AAAA 记录。
- **DuckDNS 自动更新**：先在 DuckDNS 申请免费 `xxx.duckdns.org`，再填写域名和 Token。

Cloudflare Token 需授权相应域名的**区域读取**和 **DNS 编辑**权限。节点直连需要“仅 DNS”，自动配置会关闭该记录的橙云代理。请选择 IPv4 或 IPv6，并清理指向旧地址的其他 A / AAAA 记录。

自动配置会立即更新一次，成功后设置**每 5 分钟**检查：systemd 使用 timer，其他系统使用 cron；使用 cron 时需要预先安装并启动 cron 服务。Token 输入不回显，保存在权限为 `600` 的本机配置文件中。

主菜单 **6 → 3** 或 `xnode ddns` 可以配置、查看最近成功时间、立即更新或停止更新。配置过的域名可以在后续创建时直接回车复用。

请让一个设备负责更新同一个域名。NAT 下，本机检测到的出口 IP 必须与入站映射的公网 IP 一致；如果服务商入口和出口不同，请让上游设备更新 DDNS，并选择“已有 DDNS”。**DDNS 负责地址变化，公网映射端口变化仍需同步更新映射和节点端口。**

## 自定义创建和后续修改

主菜单 **6 → 1** 自定义创建：先选协议，再设置名称、加密算法或 Reality 伪装域名，最后按网络环境填写地址和端口。

名称支持中文，回车自动命名；快速创建和自定义创建都支持三种协议。Reality 默认使用 `www.microsoft.com:443` 作为伪装站点，自定义时可以修改为服务器可访问、支持 TLS 1.3 的站点。**Reality 伪装域名与客户端连接的 DDNS 域名是两个地址**：连接地址可以是 IP、自己的域名或 DDNS，不需要为其申请 TLS 证书。

创建 Reality 前会检查服务器能否直接与伪装站点完成 TLS 1.3 访问；失败时停止创建，请检查服务器出站网络，或在自定义创建中更换伪装域名。

**Reality 创建后不能连接：** 运行 `sudo xnode diagnose`，或在主菜单 **5 → 4** 诊断。它会检查内核配置、服务、本机 TCP 监听、分享公钥与服务端私钥是否一致，以及伪装站点的 TLS 1.3 访问。基础检查通过后，会临时启动只监听本机的 Xray 客户端，实际通过当前 Reality + Vision 节点访问 HTTPS，检查握手和代理请求；结束时自动停止临时客户端并删除临时配置。输出不包含 UUID、密钥和分享链接。只检查一个节点可使用 `sudo xnode diagnose 节点名称`。

本机握手和代理请求通过后，仍需从客户端验证公网连接：**SS 和 Reality 使用不同端口时，要分别放行**；NAT 必须将 Reality 的公网 TCP 端口映射到对应本机端口。自检直接连接本机入站，不依赖 NAT 回环或 DDNS 解析。客户端需支持 Reality 和 Vision，并使用最新分享链接；请保留握手报错以便进一步排查。

主菜单 **4** 选择节点后：

| 选项 | 功能 |
| --- | --- |
| 1 | 查看连接信息 / 复制链接 |
| 2 | 导出 Xray 出站 JSON（用于 3x-ui） |
| 3 | 修改本机监听端口 |
| 4 | 修改公网地址 / DDNS / NAT 映射 |
| 5 | 删除当前节点，需输入 `确认删除` |

选择节点可输入列表序号或中文名称；只有一个节点时自动选中。NAT 节点改本机端口后，请同步调整外部映射；公网端口可以通过选项 **4** 单独修改。修改完成后重新复制链接。

出站 JSON 使用节点的**公网地址和公网端口**，`tag` 与节点名称一致。将单个对象加入 3x-ui 的 Xray 配置 **`outbounds` 数组**，再按需设置路由；请勿替换整份配置。旧版多用户 SS 节点的历史链接仍可通过主菜单 **2** 查看。

## 主菜单

```text
常用操作
  1）快速创建节点（SS / SS2022 / VLESS + Reality）
  2）查看 / 复制分享链接
  3）查看已有节点

管理与维护
  4）管理节点（连接信息 / 出站 JSON / 地址与端口）
  5）服务管理（状态 / 重启 / 日志）
  6）高级设置（自定义创建 / 内核 / DDNS / 卸载）

  0）退出管理系统
```

高级设置顺序为：**1 自定义创建、2 内核版本、3 DDNS、4 系统检测、5 完全卸载**。各子菜单输入 **0** 返回，主菜单输入 **0** 退出。

菜单显示当前内核、服务状态和节点数量。支持颜色的终端显示彩色分组，重定向输出使用纯文本；`NO_COLOR=1` 可关闭颜色。结果留在终端中，方便复制链接。

## 常用命令

```bash
xnode                  # 打开中文管理菜单
xnode add              # 选择协议、网络环境，快速创建
xnode custom           # 自定义创建
xnode links            # 查看全部节点分享链接
xnode list             # 查看序号、本机端口、公网端口、协议
xnode show             # 选择节点，查看连接信息或出站 JSON
xnode status           # 查看服务状态
xnode logs             # 查看运行日志
xnode diagnose         # 检查 Reality 配置、密钥、监听和伪装站点
xnode ddns             # 配置 / 管理 DDNS 自动更新
xnode ddns-update      # 立即更新 DDNS
xnode install-default  # 安装 / 切换到默认 Xray v26.6.1
xnode check            # 检测系统兼容性，无需 root
```

除 `check` 和帮助外，管理命令需使用 root 或 `sudo`。

## 更新、备份和卸载

**更新工具：** 重新执行安装命令即可。保留现有节点、密码、地址、NAT 映射、DDNS 配置和当前内核版本。新增网络信息单独保存，兼容旧节点。

**更新 / 切换内核：** 主菜单 **6 → 2**，选择正式版、预发布版或输入版本号；回车使用默认版本。安装时验证 SHA256，切换前检查现有配置。

**备份：** 保存 `/etc/xray-ss`，其中包含节点配置、连接地址、NAT 信息、Reality 公钥元数据和 DDNS 凭据，请妥善保管。配置变更会自动备份旧 Xray 配置。

**完全卸载：** 主菜单 **6 → 5**，输入 `确认卸载`。停止本工具的 DDNS 定时任务，删除本工具管理的节点、密钥、DDNS Token、配置备份、服务和内核，完成后退出菜单。远端 DNS 记录保留。

## 系统支持

支持常见 Linux 发行版和多种 CPU 架构，具体以内核官方发布包为准。支持 systemd、OpenRC、SysVinit、runit、procd；无法识别服务管理器时使用手动模式，手动模式不支持 Xray 开机自启。

安装前运行 `bash xray-ss.sh check` 可检测兼容性，无需 root。正式运行时尝试自动补齐基础依赖。
