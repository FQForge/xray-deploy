# Xray 节点管理工具使用方法

## 一、一键安装

在 Linux VPS 中执行：

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/fengqi0216/xray-deploy/main/install-xray-ss.sh)"
```

使用 root 用户；普通用户需具备 `sudo` 权限。

## 二、打开管理菜单

```bash
xnode
```

普通用户可以运行 `sudo xnode`。

首次使用时，选择 **1** 安装 Xray 内核（默认 `v26.6.1`，也可以选择其他版本），再选择 **2** 添加节点。

创建节点时依次输入中文节点名称、选择 SS / SS2022 加密方式、输入端口（回车随机端口），然后按提示选择连接地址：

```text
此节点是否使用域名（含 DDNS）作为连接地址？[y/N]：
```

- **直接回车或输入 n**：自动获取当前 VPS 公网 IP；自动获取失败时可以手动输入公网 IP。
- **输入 y**：填写已解析到 VPS 的域名，例如 `ss.example.com` 或你的 DDNS 域名。

创建成功后自动显示节点密码、地址和完整 `ss://` 分享链接，可复制到客户端。默认同时开启 TCP + UDP，无需选择用户模式，不生成二维码。

**注意：** 填写域名仅改变该节点分享链接中的服务器地址，不会自动配置 DNS、HTTPS 或 TLS；请先将域名解析到相应 VPS。不同节点的连接地址分别保存，互不影响。

## 三、常用命令

```bash
xnode                  # 打开中文管理菜单
xnode list             # 查看已有节点
xnode show             # 选择节点并查看连接信息
xnode links            # 查看全部节点的分享链接
xnode status           # 查看服务运行状态
xnode logs             # 查看日志
xnode install-default  # 安装默认 Xray v26.6.1
```

修改端口、删除节点、重启服务等操作可直接通过中文菜单完成。查看连接信息选择菜单 **4**。菜单 **7** 查看运行状态，菜单 **10** 完全卸载。

## 四、更新和卸载

**更新：** 重新执行一键安装命令，更新管理脚本时不会主动修改现有节点和 Xray 内核版本。此前创建的节点依然保留原连接地址。

**卸载：** 运行 `xnode`，选择菜单 **10** 并按提示确认。完全卸载会删除本工具管理的节点、密码、服务和内核，请提前备份。
